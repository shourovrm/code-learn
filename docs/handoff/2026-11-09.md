# Handoff: 2026-11-09

## What changed

Rebuild topics: a learner can rebuild some topics of a course, or all of them, from the Learn page.

- Core: `rebuildTopics(ws, course, concepts, { replace })` in `src/app/rebuild.ts`. With `replace`, the chosen topics' lessons and the exercises only they cover go, with their learner files, and a `rebuild` event resets their progress. Lesson ids and exercise slugs are never reused, since their events stay in the log. Without `replace`, nothing changes on disk.
- Learner model: `rebuild` event in `src/schemas.ts`; `replay` in `src/learner.ts` starts each listed concept afresh.
- Desktop: `rebuildTopics` in the API, IPC validation, `live.ts` (cancels jobs still writing those topics, calls core, starts a lesson job per chosen topic, then schedules), `mock.ts` mirror, and the Learn page select mode (`Rebuild.tsx`, `CourseMap.tsx`, `Path.tsx`, `app.css`).
- Docs: `docs/DESIGN.md` (storage, rebuild, learner events) and `docs/desktop/DESIGN.md` (lessons storage, course map).
