# Handoff 2026-11-10: 0.2.2

## What changed

- Authoring rules (`src/templates.ts`): an exercise or quiz uses only its own topic and the ones before it. `next_step`'s author step carries `taught`, the titles of the roadmap's earlier topics (`src/app/exercises.ts`). Lessons now open with a recap of the previous topic and a "New words" list, show a small example before each rule, and stay at about five minutes. They end with a "Remember" section of 3 to 5 short facts, before the self-check.
- Learn page: every topic opens, each with a progress line: lessons read, checks, mastery, or Not started. `TopicView` gains `checks` and `requires`. A topic checked before keeps its activity `open` after the course moves on.
- Exercise footer: Previous and Next step through every topic ("Topic N of M"). A topic with an open or passed activity opens its exercise; any other opens its topic page.
- Lesson page: the panel has "‹ All topics", "N of M done", the next topic and "Hide panel". "Lesson N of M · about X min" sits above the title. The text column is 66ch with 1.75 line height. A top-level "Answers" section becomes a `details` element behind "Show answers" (`lessonParts` adds an `answers` part).
- A topic with no lessons offers "Write this topic's lessons", plus what it builds on and a warning for any of those not started. The new `writeLesson(concept)` API starts that topic's lesson job (api, ipc, live, mock). Core already accepts a lesson for any roadmap topic, so the current topic doesn't move.
- Released 0.2.2: tag v0.2.2 and a GitHub release with the AppImage, built on system Electron 43.
