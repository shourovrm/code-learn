# code-learn brand assets

| File | Use |
| --- | --- |
| `code-learn-logo.svg`, `code-learn-logo.png` | Logo for light backgrounds (navy wordmark) |
| `code-learn-logo-dark.svg`, `code-learn-logo-dark.png` | Logo for dark backgrounds (light wordmark) |
| `code-learn-mark.svg` | The mark alone (a sprout growing from a cursor), for icons and avatars |
| `social-preview.png` | GitHub social preview, 1280×640 |
| `sprig.svg`, `sprig-dark.svg` | Sprig, the code-learn mascot (a seedling in a pot), on its shelf (for light and dark backgrounds) |
| `sprig-cheer.svg` | Sprig cheering, without a shelf, for any background |

The wordmark is "code-learn" in JetBrains Mono Bold (SIL Open Font License), converted to outlines so it needs no font. The PNGs are 1200 pixels wide with a transparent background. Prefer the SVGs wherever they're supported.

**Colors**

| Name | Value |
| --- | --- |
| Navy (wordmark) | `#0E2754` |
| Light (wordmark on dark) | `#F3F6FB` |
| Green gradient (sprout), top to bottom | `#3DDB6C` → `#17B04B` |
